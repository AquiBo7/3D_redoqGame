# 《一条截图》开发文档（到校段）
- 版本：v0.1｜范围：从“闹钟响起”到“进入教学楼、手机震动”｜项目：2026 Qoder 高校创造力大赛（提交截止 11 月 30 日 18:00）

## 1. 目的与范围
- 本文档用于开发“到校段”：玩家从起晚的清晨出发，赶到学校，目睹台阶上的一幕，在迟到登记处遇到林夏，并一起走向教学楼。本段同时是教学段：教会玩家第一人称移动、观察、用手机。
- 本段不包含：帖子、聊天、小游戏、找人、说服阿远、结局（均为后续章节，本段只预留接口）。

## 2. 核心设定
- 题材：网络暴力的教育游戏，全部虚构，不用真实人名、学校名和事件。
- 玩法：第一人称 3D 探索；手机震动或打开手机时切到 2D 界面，在 2D 中演绎剧情和做选择。
- 主角：新生，性别和样貌不设定（第一人称，不出现在画面里）。
- 林夏：当天早上下车崴了左脚踝，贴着药贴，走路有点跛，不是长期伤病，没有护具和拐杖。害羞、不善言辞，话很短，不愿麻烦人。穿浅黄色外套。
- 林夏的爸爸：朴实、话少，提着两个大袋子，怕女儿摔。
- 阿远：别班新生，随手拍照发帖的人。本段只作为背景人物出现：低头打字的男生，手机壳是橙色。不要特写，不要被刻意强调。
- 志愿者：迟到登记处的工作人员。
- 设计原则：选项要模糊，每个选项都像正常人会说的话，界面上不显示对错、分数和类型；后果通过角色反应和后续剧情体现。

## 3. 技术与平台要求
- 目标：手机浏览器优先（竖屏），同时兼容电脑。单个网页，可部署到 Qoder Sites 公开访问，不需要登录和后端。
- 3D：three.js，低多边形风格，几何体为主，不用大体积模型。
- 2D：HTML + CSS 做手机界面、对话框、选项。
- 数据驱动：场景、台词、选项、跳转写成一个 JS 对象（story），方便后续章节加入和队友修改文案。
- 操作：手机端点击地面移动、拖动屏幕转视角；电脑端 WASD + 鼠标。可交互物体上有小光点，点击或靠近触发。
- 降级模式：检测到卡顿时，自动关闭 3D，用静态背景和点选地点代替，保证剧情仍可通关。
- 调试面板：右上角“调试”按钮，显示当前所有状态变量和选择记录 log。
- 图片素材要压缩，单张尽量小于 500KB；背景图和角色头像做成可替换的变量。

## 4. 本段流程总览
- S1 起床（黑屏 → 睁眼）
- S2 手机教学（闹钟、群消息、备忘录、妈妈）
- S3 出门（过场）
- S4 街道（开放移动开始）
- S5 台阶一幕（观察）
- S6 进校门触发 CG
- S7 迟到登记处
- S8 同行去教学楼
- S9 结尾：手机震动，进入第二章（占位）

## 6. 各场景详述

### S1 起床
- 黑屏，闹钟响三声，被按掉；楼下行李箱滚轮声。
- 睁眼：画面由模糊到清晰，眨眼两次；窗帘缝透进强光。
- 心声字幕：“……几点了。”
- 可观察：窗外远处有人拖着行李往同一方向走；椅背挂着新生文化衫；床边行李箱没打开。

### S2 手机教学
- 点枕边手机的光点，进入手机界面（2D）。
- 锁屏时间 8:47。
- 闹钟标签：“报到！！别睡过头”（昨晚自己设的，已被按掉）。
- 迎新群（三条未读）：学姐“@所有人 新生报到 9:00 截止，请抓紧～迟到的同学直接到 A 栋一楼迟到登记处。”；群友“我到了！人好多。”；群友“有人知道宿舍怎么走吗？”
- 备忘录“新生攻略（终）”：1. 不要迟到 2. 带好录取通知书和身份证 3. 拍宿舍照发给妈妈 4. 认识三个新朋友 5. 最后检查一遍行李（备忘录时间 凌晨 3:12）。
- 妈妈的消息：08:05“起床了吗？记得吃早饭。”08:30“报到别迟到哦。”
- 回复妈妈（可选，无后续影响）：“起了起了。” / “马上出门。” / 不回。
- 退出手机后心声字幕：“……来不及了。”
- 目的：让玩家自己看出原因（昨晚太紧张，睡过头），同时学会用手机。不用旁白解释。

### S3 出门
- 椅背上的文化衫、桌上的证件袋有光点，点击自动带上（不是必须）。
- 过场：走廊、楼梯，3 秒快跑镜头，晃动明显。

### S4 街道（控制开始）
- 清晨，拖着行李的新生和家长，志愿者举着“新生报到 →”的牌子；目标光点在前方校门。
- 声音：行李轮滚动、远处广播、偶尔手机震动。
- 手机最多震动 2 次，间隔不少于 20 秒：玩家可以掏出看迎新群的新消息，也可以不看。忽略一次，phoneIgnored +1。
- 路边两位家长低声说话：“听说九点就关了。”不要刻意。
- 不设倒计时，用镜头晃动和脚步声表现赶路感。

### S5 台阶一幕
- 台阶上：一个男人背着一位穿浅黄色外套的女生，另一只手提着两个大袋子，走得很慢；周围有几个新生举着手机拍照（开学日很常见）。
- 演出（约 15 秒，不强制玩家停下）：到平地后女生轻拍男人的肩，“……放我下来。”男人：“再背一段，前面还有台阶。”女生：“……我自己能走。”他犹豫一下，放下她，袋子换到另一只手，跟在后面半步。
- 观察热点（注视超过 2 秒，或靠近触发）：
- 爸爸的两个袋子，seenBag = true
- 放下她那一刻，seenHandoff = true
- 台阶旁低头打字的男生（橙色手机壳），noticedTyper = true
- 玩家可以只顾赶路，不观察也能继续。观察到的细节会在后续章节提供额外选项。

### S6 开场 CG
- 触发：玩家进入校门触发区。
- 全屏 CG，约 5 秒，可跳过，淡入淡出。
- 画面：开学日清晨校门口全景，迎新横幅、行李箱、合影的新生；台阶上有一个很小的背影，男人背着穿浅黄色外套的女生；人群里有几个举手机的人，其中一人手机壳是橙色。林夏和爸爸占画面不到 10%，不是视觉中心，不画脸。
- 重要：第二章帖子里“被背着”的照片，是这张 CG 的裁剪。构图要留出裁剪余地。

### S7 迟到登记处
- 场景：迎新点快收摊，只剩一张“迟到登记”桌。
- 志愿者：“迟到的在这边，最后两位了。”
- 林夏慢慢走来，有点跛。选项（自然口语，无对错）：
- 把笔递给她（handedPen = true，trust +1）
- 自己先写
- 站到一旁看手机（phoneIgnored +1）
- 填原因：主角选 起晚了 / 路上耽搁了 / 迷路了（记录 reasonText，无后续影响）。
- 林夏在原因栏写了“脚崴了”，又划掉，改成“路上耽搁了”。这是演出，不强调；玩家看向表格才有字幕不提示（seenCrossedOut = true）。
- 表格上第一次出现她的名字“林夏”，不单独强调。
- 林夏掏学生证时药袋掉落，药袋光点出现：
- 捡起（picked = true）：袋里有药店小票（当天早晨时间）。选项（任选其一交还）：“给你。” / “你东西掉了。” / 默默放在桌上。林夏：“……谢谢。”trust +1。
- 不捡：林夏自己慢慢弯腰捡起，不说话。
- 爸爸站在登记处外面，提着袋子，不进来。

### S8 同行
- 志愿者翻名单：“你们俩一个班的吧，一起走。”
- 跟随林夏走向 A 栋（20 到 30 秒，速度由林夏决定，玩家可以走在旁边或后面）。
- 可选一句话（无影响）：“我陪你走一段。” / “你慢慢来。” / 不说话。林夏的回应都很短。
- 回头可以看到爸爸还站在校门口，提着袋子，看着她走进教学楼（seenFatherWatching = true）。

### S9 结尾钩子
- 到达教学楼门口，手机震动。
- 玩家可以看（内容为第二章占位，如“一条未读消息”），也可以不看。
- 本段结束，保存所有状态，显示占位页。

## 7. 状态变量

| 变量 | 类型 | 初始值 | 说明 |
| --- | --- | --- | --- |
| momReply | string | 无 | 回复妈妈的内容 |
| phoneIgnored | int | 0 | 忽略手机震动或看手机的次数，用于旁观结局 |
| seenBag | bool | false | 观察到爸爸的袋子 |
| seenHandoff | bool | false | 观察到放下她这一刻 |
| noticedTyper | bool | false | 观察到低头打字的男生 |
| handedPen | bool | false | 递笔给林夏 |
| reasonText | string | 无 | 主角写的迟到原因 |
| seenCrossedOut | bool | false | 注意到她划掉了原因 |
| picked | bool | false | 捡起药袋 |
| seenFatherWatching | bool | false | 回头看见爸爸站在校门口 |
| trust | int | 0 | 对林夏的信任 |
| harm | int | 20 | 伤害值，本段不变化，仅保留 |
| log | array | [] | 记录所有选择和观察，用于结局的足迹回放 |

- 所有状态变量不在界面上显示，只在调试面板中显示。

## 8. 与后续章节的接口（本段留下的伏笔）
- 药店小票（picked）：第二章林夏给证据时的依据。
- 林夏划掉“脚崴了”：体现她不愿麻烦人，第四章“共情”选项引用。
- 观察到低头打字的男生（noticedTyper）：第三、四章认出阿远。橙色手机壳是认人的暗号。
- 台阶一幕：第二章帖子里的两张照片，来自这里的真实经过。
- phoneIgnored：旁观结局的判定依据之一。
- seenFatherWatching：结局里“爸爸站在稍远处”的铺垫。

## 9. 画面规范
- 低多边形，柔和光影，轻微胶片颗粒；清晨冷色蓝灰，窗缝和阳光为暖黄。
- 第一人称视野略窄，走路有呼吸感晃动，跑起来晃动加大。
- 3D 人物为简化剪影，不画脸；对话时才出现 2D 立绘或头像。
- 颜色暗号：林夏浅黄外套，阿远橙色手机壳。
- 界面极简：没有血条、任务栏。可交互物体用小光点提示。
- 心声字幕：小字，居中偏下，白色半透明，淡入淡出，本段不超过 3 处。
- 不显示伤害值；本段画面保持干净，后续随着事态发酵再逐步加暗角。

## 10. 音频规范
- 环境声为主：闹钟、行李轮、广播、人声、风声。
- 音乐极轻，不抢戏。
- 手机提示音要有辨识度，后续越来越密（本段只出现 1 到 2 次）。
- 所有音频要原创或确认可商用授权。

## 12. 内容安全
- 开始页面写：“本作品为虚构，涉及网络暴力主题，可随时退出。”并提供“退出”按钮。
- 不使用真实人名、真实学校名、真实事件；手机里不出现真实品牌和应用名，用“迎新群”“备忘录”等通用名称。
- 评论一律概括表达，不写具体辱骂词；不出现自伤相关内容。
- 林夏的形象是坚强、自己想办法的人，不写成“卖惨”或“弱者”；爸爸不是反面角色。

## 13. 验收标准
- 手机竖屏和电脑浏览器都能完整走完本段，无卡死。
- 手机拿起、翻看、返回、回复妈妈都正常。
- 台阶一幕：不观察也能继续；观察热点触发后，对应变量正确记录。
- 进入校门区域一定触发 CG，且可跳过。
- 迟到登记处：三个选项都能走通；捡药袋与不捡药袋都能继续。
- 手机震动：看与不看，phoneIgnored 的值正确。
- 调试面板能显示所有变量和 log。
- 关闭 3D 的降级模式下，本段仍可通关。
- 页面首屏加载不超过 5 秒（手机 4G）。
