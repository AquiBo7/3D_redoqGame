## 1. 目的与范围
- 本文档用于开发全流程剧情：玩家从起晚的清晨出发，目睹台阶上的一幕，在迟到登记处遇到林夏，随后度过几天平静的日子；直到在食堂发现事情已经变了，并面对第一次关键选择；随后在第三章寻找发布者与倾听林夏的决定，在第四章面对阿远与“删不回”的转发洪流，最终在第五章迎来五种结局、后日谈、足迹回放、林夏的草稿箱、行动卡与成就记录。
- 第一章（S1–S9）同时是教学段：教会玩家第一人称移动、观察和使用手机。

## 2. 核心设定
- **题材**：网络暴力的教育游戏，全部虚构，不用真实人名、学校名和事件。
- **玩法**：第一人称 3D 探索；手机震动或玩家打开手机时切到 2D 界面，在 2D 中演绎剧情和做选择。
- **主角**：新生，男生（已有立绘，用于同行照片、足迹回放和画中人物；第一人称 3D 场景中不露脸）。起晚是因为昨晚太紧张，没睡好。
- **林夏**：当天早上下车崴了左脚踝，贴着药贴，走路有点跛，没有护具和拐杖，外表看不出明显的伤。害羞、不善言辞，话很短，不愿麻烦人。穿浅黄色外套。
- **林夏的爸爸**：朴实、话少，提着两个大袋子，怕女儿摔。
- **阿远**：别班新生，只发了第一张“被背着”的帖子（裁剪自开场 CG 的一角），觉得好玩，没想到会这样。第一章只作为背景人物出现：低头打字的男生，手机壳是橙色，不要特写，不要刻意强调。
- **室友小陈**：爱说话，没有恶意，是“普通人随手一笑”的代表。
- **志愿者**：迟到登记处的工作人员。
- **周老师**：辅导员，午后办公室逆光对话，尊重学生意愿，只在林夏同意时联系家长。
- **发酵逻辑**：第一张图没人在意（低热度）；热度来自后来新增的“同行照片”和质疑的说法，并且把主角本人也卷了进来。
- **设计原则**：选项要模糊，每个选项都像正常人会说的话；界面上不显示对错、分数和类型；后果通过角色反应和后续剧情体现。

## 3. 技术与平台要求
- **目标**：横屏第一人称优先（电脑宽屏与手机横屏），同时自适应兼容手机竖屏不卡死。单个网页，可部署到 Qoder Sites 公开访问，不需要登录和后端。
- **3D**：three.js（r187），低多边形与清晨电影感柔和光影，结合已压缩角色 GLB 模型。
- **2D**：原生 HTML + CSS + TS 做手机界面、对话框、选项、2D 叙事舞台、Canvas 2D 小游戏与结局复盘页。
- **数据驱动**：场景、台词、选项、跳转写成一个 TS/JS 对象（story），方便扩展与维护。
- **操作**：手机端点击地面移动、拖动屏幕转视角（双击疾跑）；电脑端 WASD + 鼠标（Shift 开关疾跑，E 交互，O 调试）。可交互物体上有小光点，点击或靠近触发。
- **降级模式**：`/?lite=1` 或检测到 WebGL 异常时，自动关闭 3D，用静态纸纹插画背景和点选地点代替，保证全五章剧情仍可 100% 通关。
- **调试面板**：右上角“调试”按钮（或 `?debug=1`），显示当前所有状态变量、选择记录 log 与跳关入口。
- **素材与热替换**：图片素材单张尽量小于 500KB；背景图、角色头像/立绘、结局 CG、小票做成可替换的资源清单变量（详见 `docs/EXECUTION_PLAN_V05.md` 美术热替换协议）。

## 4. 前半段流程总览（第一章～第二章）
- **S1** 起床（黑屏 → 睁眼，自由走动与观察）
- **S2** 手机教学（锁屏 8:40、闹钟、群消息、备忘录、妈妈）
- **S3** 出门（对准房门 3 秒快跑过场）
- **S4** 街道（开放移动开始，路上手机最多震动 2 次）
- **S5** 台阶一幕（观察：爸爸背林夏、放下、自己走、低头打字男生）
- **S6** 进校门触发 CG（校门口全景）
- **S7** 迟到登记处（递笔/先写/看手机、填原因、划掉脚崴了、捡药袋）
- **S8** 同行去教学楼（埋伏笔：回头见爸爸、路人举着手机拍风景）
- **S9** 第一章结尾：群里的合照消息（可放大找台阶上的浅黄小背影、可点赞）
- **S10** 黑屏字幕：入学几天的概况
- **S11** 宿舍：室友小陈递来手机（低热度的帖子，四选一反应）
- **S12** 食堂：找三号窗口打饭（3D，沿途旁听窃窃私语、第一次“被看见”）
- **S13** 爆发：同行照片，你被@（含匿名评论区与点击评论触发心声）
- **S14** 三个选择：解释 / 等等 / 玩笑
  - 分支：**解释** → 被回嘲 + 林夏主动加你 + 清气泡小游戏 → 第三章；**等等** → 主动加林夏说明情况 → 第三章；**玩笑** → 黑幕结局（参与者结局 `ending = 'joined'`，可“回到食堂，再试一次”或“查看足迹”）。

## 6. 第一、二章各场景详述

### S1 起床
- 黑屏，闹钟响三声，被按掉；楼下行李箱滚轮声。
- 睁眼：画面由模糊到清晰，眨眼两次；窗帘缝透进强光。
- 心声字幕：“……几点了。”
- 玩家可直接自由移动与观察：窗外远处有人拖着行李往同一方向走；椅背挂着新生文化衫；床边行李箱没打开。

### S2 手机教学
- 点枕边手机的光点，进入手机界面（2D）。
- **锁屏时间 8:40**。
- 闹钟标签：“报到！！别睡过头”（昨晚自己设的，已被按掉）。
- 迎新群（三条未读）：学姐“@所有人 新生报到 9:00 截止，请抓紧～迟到的同学直接到 A 栋一楼迟到登记处。”；群友“我到了！人好多。”；群友“有人知道宿舍怎么走吗？”
- 备忘录“新生攻略（终）”：1. 不要迟到 2. 带好录取通知书和身份证 3. 拍宿舍照发给妈妈 4. 认识三个新朋友 5. 最后检查一遍行李（备忘录时间 凌晨 3:12）。
- 妈妈的消息：08:05“起床了吗？记得吃早饭。”08:30“报到别迟到哦。”
- 回复妈妈（可选，无后续影响）：“起了起了。” / “马上出门。” / 不回。
- 退出手机后心声字幕：“……来不及了。”

### S3 出门
- 椅背上的文化衫、桌上的证件袋有光点，点击自动带上（不是必须）。
- 过场：视角强制平顺转向房门，随后 3 秒快跑镜头，晃动明显。

### S4 街道（控制开始）
- 清晨，拖着行李的新生和家长，志愿者举着“新生报到 →”的牌子；目标光点在前方校门。
- 手机最多震动 2 次，间隔不少于 20 秒：玩家可以掏出看迎新群的新消息，也可以不看。忽略一次，`phoneIgnored + 1`。
- 路边两位家长低声说话：“听说九点就关了。”

### S5 台阶一幕
- 台阶上：一个男人背着一位穿浅黄色外套的女生，另一只手提着两个大袋子，走得很慢；周围有几个新生举着手机拍照。
- 演出（约 15 秒，不强制玩家停下）：到平地后女生轻拍男人的肩，“……放我下来。”男人：“再背一段，前面还有台阶。”女生：“……我自己能走。”他犹豫一下，放下她，袋子换到另一只手，跟在后面半步。
- 观察热点（注视超过 2 秒，或靠近触发）：
  - 爸爸的两个袋子，`seenBag = true`
  - 放下她那一刻，`seenHandoff = true`
  - 台阶旁低头打字的男生（橙色手机壳），`noticedTyper = true`

### S6 开场 CG
- 触发：玩家进入校门触发区。
- 全屏 CG，约 5 秒，可跳过，淡入淡出。
- 画面：开学日清晨校门口全景，迎新横幅、行李箱、合影的新生；台阶上有一个很小的背影，男人背着穿浅黄色外套的女生；人群里有几个举手机的人，其中一人手机壳是橙色。林夏和爸爸占画面不到 10%，不是视觉中心，不画脸。
- **复用**：S9 群里的合照消息使用同一张全景；S11 宿舍里的帖子图，是这张 CG 台阶一角的裁剪。

### S7 迟到登记处
- 场景：迎新点快收摊，只剩一张“迟到登记”桌。
- 志愿者：“迟到的在这边，最后两位了。”
- 林夏慢慢走来，有点跛。选项（自然口语，无对错）：
  - 把笔递给她（`handedPen = true`，`trust + 1`）
  - 自己先写
  - 站到一旁看手机（`phoneIgnored + 1`）
- 填原因：主角选 起晚了 / 路上耽搁了 / 迷路了（记录 `reasonText`，无后续影响）。
- 林夏在原因栏写了“脚崴了”，又划掉，改成“路上耽搁了”。玩家看向表格才有字幕（`seenCrossedOut = true`）。
- 表格上第一次出现她的名字“林夏”，不单独强调。
- 林夏掏学生证时药袋掉落，药袋光点出现：
  - 捡起（`picked = true`）：袋里有药店小票（当天早晨 07:52）。选项（任选其一交还）：“给你。” / “你东西掉了。” / 默默放在桌上。林夏：“……谢谢。”`trust + 1`。
  - 不捡：林夏自己慢慢弯腰捡起，不说话。
- 爸爸站在登记处外面，提着袋子，不进来。

### S8 同行
- 志愿者翻名单：“你们俩一个班的吧，一起走。”
- 跟随林夏走向 A 栋（20 到 30 秒，速度由林夏决定，玩家可以走在旁边或后面）。
- 可选一句话（无影响）：“我陪你走一段。” / “你慢慢来。” / 不说话。
- 回头可以看到爸爸还站在校门口，提着袋子，看着她走进教学楼（`seenFatherWatching = true`）。
- **伏笔**：路上有学生举着手机，在拍校园和合影，没有人特别注意（玩家注视/注意到则 `noticedPhoneBehind = true`）。S13 的同行照片来自这里。

### S9 第一章结尾：群里的合照消息
- 触发：到达教学楼门口，手机响（普通通知声）。
- 内容：迎新群里，学姐发“开学第一天照片合集～”（时间约 8:50），其中一张就是 S6 的全景图。群友评论都很普通：“我在左边！”“好多人啊。”没有人提到台阶上的人。
- 玩家可以放大图片，自己寻找台阶上穿浅黄色外套的小背影；找到并点击该区域则 `noticedPhoto = true`（不弹奖励提示）。
- 可以点赞合照（`likedPhoto = true`），只是记录。
- 舆论没有发酵，`harm` 不变。关闭手机后进入 S10 黑屏字幕。

### S10 黑屏字幕：入学几天
- 黑屏，字幕逐行淡入淡出，每行约 2 秒，可跳过。
- 字幕文案：
  1. 入学第三天，你记住了室友的名字。
  2. 第五天，班群里有了第一个表情包梗。
  3. 食堂的酸辣粉，比想象中好吃。
  4. 走廊里偶尔遇到她，点点头，她也点点头。
  5. 一切都很顺利。
  6. 顺利得你几乎忘了，那天台阶上的事。
  7. 直到……

### S11 宿舍：室友递来手机
- 场景：宿舍，2D 舞台为主。室友小陈把手机递到你面前：“你看，有人被爸爸背着来报到。”
- 帖子：图片是 S6 CG 台阶一角的裁剪（发布时间 8:52），配文“新生报到名场面”，浏览数很小（如浏览 68 · 评论 3）；评论只写概括，如“一条轻松的评论（有点可爱、爸爸辛苦了）”，没有恶意。
- 如果 `noticedPhoto === true`，触发心声字幕：“这是那张合照的一角。”
- 玩家的反应（四选一，全部自然口语）：
  1. “哈哈。”（`roommateReply = '哈哈。'`）
  2. “她好像是脚崴了。”（`roommateReply = '她好像是脚崴了。'`；小陈：“哦，那也挺不容易的。”）
  3. 看一眼，把手机还给他。（`roommateReply = '（看一眼还给他）'`）
  4. “这是我们班的吧。”（`roommateReply = '这是我们班的吧。'`，`pointedOut = true`，`harm + 3`；小陈：“真的？哪个？”，足迹回放会点出这一句）

### S12 食堂：找窗口打饭（3D + 降级兼容）
- 触发：S11 结束，场景切到食堂，第一人称。
- 任务：找到指定窗口（**三号窗口**）打饭，光点指向目标，不设时间限制。
- 沿途氛围：排队和就餐的人在低头看手机，三五人聚在一起低声说话；走近时触发片段字幕：
  - 旁听点 1：“……明明能自己走……”（走近时声音停一下，目光移开，`canteenSeen + 1`）
  - 旁听点 2：“……跟她一起的那个……”（走近时声音停一下，目光移开，`canteenSeen + 1`）
  - 旁听点 3（窗口前）：前面的人抬头对比了一眼你，又低下头（`canteenSeen + 1`）。
- 打到饭后（与三号窗口交互），手机震动，进入 S13。

### S13 爆发：同行照片
- 小陈的消息：“你快看帖子。”
- 打开手机：帖子里新增了一张图，是你和林夏并肩走路的样子，她在自己走；配文质疑她是否夸大了；你被@；浏览数和评论数明显上涨（如浏览 4,820 · 评论 136）。
- 评论区（全部匿名用户）：
  - 匿名用户 A（赞 142）：“这个女生既然可以自己走路，为什么还要被背着？”
  - 跟评 · 匿名用户 B（赞 89）：“是啊，这也太不体谅父母了。”
  - 匿名用户 C（赞 318）：“这个男生跟她一起玩，是不是也是这样的人？”
  - 跟评 · 匿名用户 D（赞 246）：“肯定是，毕竟臭味相投哈哈哈。”

  - 点第一条（匿名用户 A）：“……他们只看见了她走路的那一张。”
  - 点第三条（匿名用户 C）：“……原来，站出来是要被一起算进去的。”

| **最好 (`best`)** | 脚好了，开始在校园里画画，有时在最后一排，有时在台阶上。她仍然话少，但会主动回你一句完整的话。爸爸送她到校门口后只站在原地，看着她自己走进去。阿远在班群里发了一条澄清和道歉，没有多少人回应，他没有删。 | 你把那幅画夹在笔记本里。以后看到别人被拍、被议论，你会先想一想“前面发生了什么”。 | **外界依然各说各话。但有人记得完整的那一天。** |
| **中间 (`middle`)** | 帖子没了，话题散了。林夏照常上课，更少举手，也更少在走廊停留。阿远再也没发过什么。 | 你有时会想起那天的台阶，想起自己只做了一半。你开始分得清“删了”和“处理好了”不是一回事。 | **删了，不等于说完整了。** |
| **最差 (`worst`)** | 对话截图传开，阿远成了新的话题。林夏请了几天假，回来后座位没变，只是更久地低着头。 | 你以为自己在讨公道，用的却是同样的方式。之后每次想“揪出”谁，你都会停一下。 | **为她出头，不等于把另一个人推出来。** |
| **旁观 (`bystander`)** | 一个月后没人再提。她仍坐在最后一排，脚好了，话更少。走廊里遇见，你们互相点点头。 | 你记得自己看过的每一条，却说不出自己做过什么。后来你偶尔点开那条沉底的帖子，什么也没有改变。 | **你什么都没做。她那天，也什么都没等到。** |
| **参与者 (`joined`)** | 帖子的浏览数多了一个零。林夏的座位空了几天，回来后没有再提那天的事。 | 你没想到那句玩笑会被截图，被放进另一个话题里。你把它删了，但别人早已存下。 | **笑一下，也是在场。** |

3. **足迹回放（按玩家实际状态与 `log` 生成客观陈述卡片，不说教）**：
   - 台阶一幕：你看见了什么（爸爸的袋子 / 放下她的瞬间 / 低头打字的男生）
   - 群里合照：是否找到了台阶上的小背影、是否点了赞
   - 宿舍递手机：你对小陈说了什么（若 `pointedOut` 则点出“你说过：‘这是我们班的吧。’”）
   - 食堂打饭：你留意到了几处低语与目光
   - 帖子爆发（S14）：你选择了“解释”、“等等”还是“玩笑”
   - 寻找发布者（C5）：你通过哪种方式找人、在走廊认错了几次人
   - 侧楼梯平台（D2–D4）：三轮对话你的选择倾向，以及你说过的那句 `phrase`
   - 守护小游戏（D5）：你击败了多少气泡、水晶被击中了多少次、是否有人与你并肩
4. **林夏的草稿箱（按 `trust` 阈值解锁）**：
   - `trust >= 1` 解锁第 1 条：“今天是不是该告诉爸爸？……还是算了。我不想麻烦大家。”
   - `trust >= 3` 解锁第 2 条：“那个人替我说了一句话。原来有人看见了。”
   - `trust >= 5` 解锁第 3 条：“想把那天早上的台阶画下来。画成完整的。”（若 `trust < 5` 则显示未解锁态：“想画给他，但……”）
   - `trust >= 7` 解锁第 4 条（最高信任隐藏心声）：“我不能让爸爸出来。他那么笨嘴拙舌的人，要是看到那些话……他会以为，是他的错。”
5. **行动卡（现实反网暴温和指南）**：
   - 转发或评论前先停一秒：我看到的是一整件事，还只是一张被截取的图？
   - 保存证据前先询问当事人意愿，不替受害者做公开决定。
   - 遇到校园网络暴力，优先通过平台举报、联系可信任的老师或家长处理，不以暴制暴、不发动新的围猎。
   - 私下一句温和的“我在”或正常的同行，比在评论区对骂更能托住当事人。
   - 如感到持续心理压力，可随时向学校心理咨询中心或青少年心理援助热线求助。
6. **底部操作按钮**：
   - 参与者结局专属：**“回到食堂，再试一次”**（读档回 S12/S14）
   - 旁观结局专属：**“回到第二天，再试一次”**（读档回 C1）
   - 通用按钮：**“章节选择”** / **“从头开始”** / **“查看成就”**
