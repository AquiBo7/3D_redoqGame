# 《一条截图》Hack4Good 核心功能改造方案与 Qoder 手把手操作指南

> **适用对象**：负责在 **Qoder** 中实现本次“交互式法治与现实提示 + 理性劝解选项 + 结局三视角清单”的队友。  
> **核心理念**：保持《一条截图》第一人称旁观者的叙事纯粹性与自由选择权——**不说教、不打分、不替玩家做决定**；只在命运分岔口为玩家点亮一颗可选的 **`[Y]` 现实与法治提示灯**，并在终章沉淀一张**与亲历节点一一对应的三视角反网暴与普法清单**。

## 一、完整改造方案蓝图（先看懂我们要做什么）

### 1.1 整体架构与红线（严守 [AGENTS.md](file:///E:/3D_Qoder/AGENTS.md)）
- **绝对不改写**既有 2D 手机原稿文字（`story.ch1~ch4` 的手机帖子/群聊原稿不动）。
- **绝对不出现**真实校名、真实 App 名（统一称“平台/校园墙/班群/私信”）、具体辱骂词、自伤暗示、以及“得分/正确率/伤害值/信任度/标准答案”等评判词汇。
- **模块严格隔离**：`src/data/`（纯数据）→ `src/core/`（纯逻辑投影，禁 `three`）→ `src/ui/`（纯展示，禁 `three`）；全程 `ES2020` 语法、`TypeScript strict: true`。

### 1.2 三大核心改造内容

#### ① 关键分岔口 **`[Y]` 现实与法治提示系统**（双端兼容）
- **触发时机**：当剧情走到以下 **6 组高光关键选择节点** 时，选项栏上方柔和亮起一颗克制的提示条：  
  `按 [Y] 查看现实做法与法治参考`（**电脑端按键盘 `Y` 键开关；手机/触屏与鼠标直接点击即可开关**）。
- **卡片结构（不剧透“选哪项”，只给客观坐标）**：
  1. **【现实常规做法】**：遇到此类真实校园网暴情境时，最稳妥有效的应对动作；
  2. **【法治知识参考】**：精准引用中国现行法律条款 + 1 句大白话释义；
  3. **【镜头外提醒】**：点出此时林夏（受害者）或阿远（推手）所处的真实压力，**最终选哪项完全由玩家自己决定**。

| 节点编号 | 对应剧本 `stepId`（精准绑定） | 触发情境 | 现实做法 + 精准法律依据（已核实） |
| :---: | :--- | :--- | :--- |
| **N1** | `s14-choice` | 第二章：帖子刚爆发（解释 / 等等 / 开玩笑） | **旁观者 5D 正向干预法**（理性陈述事实、转移降温、私下陪伴、拒绝随手玩梗助推）；**《民法典》第 1024 条**（任何组织或者个人不得以侮辱、诽谤等方式侵害他人的名誉权——断章取义与二次起哄同样可能构成侵权助推）。 |
| **N2** | `s14-evidence`、`c4-response` | 第二、三章：留存小票证据 / 面对林夏拒绝让父亲出面 | **受害者合法固定电子证据四要素**（完整录屏含页面 URL、发布者账号 ID、发布时间、浏览转发量；先存证再拉黑）；**协助留证必须先征得当事人意愿**，避免二次心理创伤。 |
| **N3** | `c3-response` | 第三章：与辅导员周老师沟通求助 | **正规校内与平台联动路径**（辅导员、学校心理咨询中心、平台侵权投诉绿色通道）；**《民法典》第 1195 条**（网络侵权“通知—删除”规则：权利人提交初步证据通知平台，平台应及时采取删除、屏蔽、断开链接等必要措施）。 |
| **N4** | `c5-find-path` | 第三章：寻找发布者（走廊辨认 / 请管理员转达 / 校园墙公开喊话） | **严守拒绝“人肉开盒 / 以暴制暴”底线**；**两高一部《关于依法惩治网络暴力违法犯罪的指导意见》**（明确依法惩治借“伸张正义”名义发动人肉搜索、公开隐私、引导新围猎的二次网暴行为）。 |
| **N5** | `d2-round-1`、`d2-round-2`、`d2-round-3` | 第四章：侧楼梯平台劝解阿远（推手视角核心交锋） | **理性、有据、不施压的劝解止损法**；**《民法典》第 1024 条 + 《治安管理处罚法》第 42 条**（即便未写姓名、没骂脏话，只要内容足以指向特定人且断章取义引发侮辱诽谤与网暴，发布者仍须承担民事侵权责任，情节严重的可面临行政拘留与罚款）。 |
| **N6** | `d4-team-phrase`、`d4-solo-phrase`、`d6-team-response`、`d6-solo-response` | 第四章：原帖删了但截图被二次搬运 / 走廊善后陪伴林夏 | **二次搬运维权与推手完整止损法**：受害者继续依 **《民法典》第 1195 条** 向搬运账号及平台批量发侵权通知并留存证据；推手必须明白“偷偷删帖 ≠ 结束”，应留存原始记录并发布客观完整澄清；旁观者温和托住并按需协助联系专业心理援助。 |

#### ② 旁观者剧情中的 **2 处精准“理性与法治劝解”可选分支**（保留完全自由）

  - 不替林夏越权做决定，只递出清晰、可靠的支持。

#### ③ 结局页升级：《关键节点 · 三视角应对与法治清单》
- 在 [src/core/endingReview.ts](file:///E:/3D_Qoder/src/core/endingReview.ts) 与 [src/ui/chapterEnd.ts](file:///E:/3D_Qoder/src/ui/chapterEnd.ts) 中：
