### 8.1 优化思路：四条原则

1. **获取也自动化。** 第五节原本要求「你手动下载」，但素材一旦靠人手拿，来源、版本、许可证就断链。改成 `node tools/fetchProps.mjs`：脚本按清单调 Poly Haven 公开 API，下载散件包（`.gltf` + `.bin` + 贴图）并合并成单体 `.glb`，同时写出 `art/props_raw/SOURCES.md` 记录每件素材的作者 / 来源链接 / 许可证。重跑一次就能复原全部原料，评委问「这个模型哪来的」时答案在仓库里，而不是在聊天记录里。
2. **标准化用无头 bpy，不靠人手点 DCC。** 原始要求是美术在 Blender 里手工做完六件事再导出，本文 6.8 则设想用纯 `gltf-transform` 脚本一把过；实测两者都不够——脚本要的是**几何与材质**的标准化（合并子网格、贴地居中、按真实米数缩放、哑光统一），gltf-transform 只管压缩，手工又不可复现。所以拆成：`tools/blender_prop_pipeline.py` 做六步标准化，gltf-transform 只做最后的 meshopt 复压。收益不在省时间，在于**结果可复现、可回滚、可审计**：任何一件重跑产出完全一致，参数（目标高度表、面数预算、哑光区间）是代码里的常量，而不是某人当天的手感。
3. **用游戏同款加载器验收，不用 DCC 预览图。** 减面和量化后的真实代价只有在运行时才看得见。最终验收写成 `tools/checkProps.mjs` + `tools/props-check.html`：起本地服务，在真实浏览器里用 `three@0.187.0` 的 `GLTFLoader` + `MeshoptDecoder` 解码 `public/models/props/*.glb`，量**运行时真值**（三角面数 / DrawCall / 包围盒底面 Y / 实测高度 / Roughness / Metalness / 是否透明 / 底图分辨率），并逐件出正、背两张图供目检「全黑、法线反转、倒立」。Blender 里好看不算数，游戏里贴地、不翻面、一个 DrawCall 才算数。
4. **制作与挂载彻底分离。** 本轮**一个业务场景文件都没动**，只新增工具与素材；改场景时按 `docs/道具挂载工单.md` 一场景一张单派发（红线：保留现有 interactables / zones / Mesh 命名与碰撞盒，改完 `npm run test && npm run build` 全绿 + 截图对比）。这是防止「一口气改 7 个 3D 场景」把坐标契约改崩的唯一有效手段。

### 8.3 六步标准化（`tools/blender_prop_pipeline.py`）

1. **合并子网格**：`join` 所有部件，多材质收进同一 mesh 的 material slots，DrawCall 最多 9→1。
2. **贴地 + 居中到原点**：包围盒底面归零、XY 质心归零，导出后场景里不用再手写 `position.y` 补偿。
3. **按内置真实米数缩放**：脚本里一张 `REAL_HEIGHT` 表（床 0.90 / 桌 0.75 / 椅 0.85 / 长椅 0.80 / 垃圾桶 0.85 / 路灯 4.20 / 行李箱 0.65 / 文具 0.18 米），统一按**高度轴**缩放，保证同画面内道具之间比例自洽。
4. **减面**：默认 `auto`——原始面数与预算之比 ≤20 用平面坍缩（DISSOLVE，保形），比值更大时平面坍缩保不住结构，退化为精确 COLLAPSE 按比例减；目标 500 三角面。
5. **统一哑光材质**：Roughness 拉进 0.80–0.92（实测统一 0.86）、Metallic 压到 ≤0.15（实测 0.00）、去高饱和、修复断法线、底图降到 512² 并重打包 JPEG。
6. **导出 + 打印证据表**：`【原面数 → 减面后 → 复压前体积】`，末尾汇总材质与贴图处理明细。

最后复压交给 `@gltf-transform/cli` 的 `meshopt --level high`（几何/属性量化）。**注意语义**：meshopt 会把原点重基到 `node.translation` / `node.scale`，所以第 2 步的「贴地」在 Blender 里看不出来，必须以运行时 `Box3` 为准——`tools/checkProps.mjs` 实测 8 件 `底面Y = 0.0000`，贴地结论成立。
