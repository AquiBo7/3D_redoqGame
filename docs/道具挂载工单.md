## 6. 美术润色（挂在每张工单里顺手做掉，别单独攒一批）

1. **统一色温，压掉写实旧化**（最大违和点）。Poly Haven 底图带锈迹、磨损、贴纸。`baseColorTexture` 会与 `material.color` 相乘，所以挂载时给道具材质设一个贴近场景家具的中性暖色即可，不用重导出：
   - 木器（长椅 / 课桌 / 讲台侧）：`0xb9a07f`
   - 金属（路灯 / 垃圾桶 / 铁艺椅）：`0x8f949b`
   - 纸张书本（文具）：`0xd8cbb4`
   roughness 保持 0.86、metalness 0（道具已按此标准化，`shared.ts:37 createMatteMaterial(color, roughness=0.92)` 是同一套口径）。若还觉得脏，再回来调 `tools/blender_prop_pipeline.py` 的 `SATURATION_MAX` 0.45→0.30 重跑单件。
2. **接触阴影**：扫描/建模资产落地容易「飘」。照项目既有做法（`schoolInterior.ts:494 desk-contact-shade`）给每件大道具补一片离地约 0.02m 的深色圆片，比把阴影调硬更省、也更像本项目风格。
3. **阴影开关**：桌椅 / 长椅 / 路灯 `castShadow + receiveShadow`；文具等小件只 `receiveShadow`，少一次阴影 pass。three 0.187 只允许 `PCFShadowMap`。
4. **打破重复感**：8 套课桌椅一模一样会显得假。2–3 套加文具、1–2 把椅子 yaw 偏 5–12°、用 `InstancedMesh.instanceColor` 做 ±4% 明度抖动——零额外 DrawCall。
5. **比例复核**：路灯 4.20m 比角色（1.62–1.78m）高出一倍多，挂载后先看 S4/S7/S8 截图确认灯罩没戳进屋檐。**别改道具高度**（高度表是验收过的），改摆放点。
6. **两只一组的素材**：`prop_trashcan` / `prop_suitcase` 都是成对的。垃圾桶在 S4 正好当「双格桶」；若某处只需要一只箱子，别硬缩放（会变扁箱），回来告诉我，我把那一只单独导出成 `prop_suitcase_single.glb`。
