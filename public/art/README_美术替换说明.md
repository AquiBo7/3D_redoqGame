# 《一条截图》美术资产热替换交接说明（给美术队友）

本目录（`public/art/`）用于存放《一条截图》全五章的 **2D 角色立绘、全屏/半屏剧情 CG、道具小图、2D 舞台背景与成就奖杯图标**。

## 一、如何替换美术图（零代码改动）

1. **在你们还没交图之前**：游戏已经内置了全套程序化 Canvas/SVG 插画与剪影兜底，可以完整跑通 1～5 章和 5 个结局，且不会报任何 404。
2. **当你们画好任意一张或多张图后**：
   - 只需要将图片导出为 `.png`（建议单张压缩到 **500KB 以内**），**严格按照下表的【放置路径与文件名】**放入对应子文件夹（如 `public/art/portraits/`、`public/art/cg/` 等）；
   - 然后在项目根目录运行一次构建命令：
     ```bash
     npm run build
     ```
     （或运行 `node tools/syncArtAssets.mjs`）
   - 构建脚本会自动识别你们放入的新图片并替换掉默认程序化插画，无需修改任何 TypeScript 代码！

---

## 二、合规与风格红线（天池竞赛必查）

1. **允许使用 AI 辅助出图**：赛题已确认允许 AI 生成素材，但**请务必保存所用 AI 工具的使用条款截图与生成记录**（放入 `docs/qoder-log/` 备查）。
2. **禁止真实人脸与真实品牌**：
   - 所有角色均为**日系治愈/低饱和叙事插画或半剪影风格，不出现写实真人照片脸**；
   - 画面、衣服名牌、小票、背景里**严禁出现任何真实校名、真实医院/药店名、真实品牌 Logo 或微信/抖音等真实 App 界面**。
